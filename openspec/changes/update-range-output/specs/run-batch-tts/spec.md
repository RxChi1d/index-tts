## MODIFIED Requirements
### Requirement: 檔案選取與合併
腳本 MUST 讀取指定資料夾內的 `.txt` 檔案路徑，排序規則為「檔名前綴數字優先，無前綴置後；前綴相同再依檔名排序」，並以 1-based 含起訖的範圍選取檔案；若範圍超出可用檔案數或起訖不合法，腳本 MUST 報錯並停止。選取後需移除所有換行字元（包含檔案內與檔案間）並串接成單行文字。

#### Scenario: 選取指定範圍
- **WHEN** 資料夾有 40 個 `.txt` 且範圍設定為 21–40
- **THEN** 腳本使用排序後第 21–40 個檔案合併。

#### Scenario: 範圍超出可用數量
- **WHEN** 資料夾只有 10 個 `.txt` 但範圍設定為 21–40
- **THEN** 腳本回報錯誤並停止。

#### Scenario: 未補零排序仍正確
- **WHEN** 檔名包含 `1-xxx.txt`、`2-yyy.txt`、`10-zzz.txt`
- **THEN** 腳本的選取順序為 1、2、10。

## ADDED Requirements
### Requirement: 輸出檔名依範圍命名
腳本 MUST 在有範圍設定且未指定自訂輸出路徑時，依所選取的檔案範圍自動命名輸出檔案，固定 3 位數格式並輸出到 `outputs/`（例如 `021-040.wav`）。

#### Scenario: 範圍輸出命名
- **WHEN** 選取範圍為 21–40
- **THEN** 輸出檔案名稱為 `021-040.wav` 且位於 `outputs/`。

### Requirement: 執行前列印選取清單
腳本 MUST 在開始 TTS 前輸出選取檔案清單，且順序 MUST 與實際串接一致。

#### Scenario: TTS 前可檢視選取順序
- **WHEN** 使用者設定範圍並啟動腳本
- **THEN** 主控台會列出完整檔案清單，順序與實際串接一致。
